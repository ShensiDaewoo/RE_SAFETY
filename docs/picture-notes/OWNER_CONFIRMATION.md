# 그림 자산 공개 확인

2026-11-15, 프로젝트 소유자(팀)가 확인했다.

- 질문: "앱에 들어간 그림 7장은 직접 만드셨고 공개해도 되는 것이 맞습니까?"
- 답: "맞아, 공개 가능"

대상 (대표 시연본 APK의 `assets/assets/hmi/`):

| 파일 | 쓰임 |
|---|---|
| `HMI_STAGE_READY.webp` | 주행 준비 화면의 오로라 배경 |
| `HMI_STAGE_ACCIDENT.webp` | 사고 화면의 오로라 배경 |
| `HMI_BG_01_NORMAL.png` | 주행 준비 차량 장면 |
| `HMI_BG_02_ACCIDENT.png` | 사고 차량 장면 (경고 삼각대를 지운 편집본) |
| `SEATCTL_CAR_TOP.png`, `SEATCTL_SEAT_3D.png`, `SEATCTL_SEAT_SIDE.png` | 좌석 제어 화면 (ChatGPT로 만든 그림에서 자름) |

이 폴더의 JSON 메모는 그림을 받은 2026-11-14 시점의 기록이라 "공개 조건 미확인"이라고 적혀 있다. 이 문서가 그 뒤의 확인이다.

범위 밖: 프로젝트 초기에 참고용으로만 쓴 다른 콘셉트 이미지(`si.png`)는 이 확인에 들어 있지 않으며, 이 저장소와 APK에 들어 있지 않다.
